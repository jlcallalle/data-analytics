import re

def procesamiento_texto(texto):
  texto = texto.lower()
  texto = re.sub(r'[-]', '', texto)
  texto = re.sub(r'á', 'a', texto)
  texto = re.sub(r'é', 'e', texto)
  texto = re.sub(r'í', 'i', texto)
  texto = re.sub(r'ó', 'o', texto)
  texto = re.sub(r'ú', 'u', texto)
  texto = re.sub(r'ï', 'i', texto)
  texto = re.sub(r'ü', 'u', texto)
  return texto

2. Análisis de los 6 registros

En la muestra tenemos 6 pasajeros:

Sobrevivieron: 3
No sobrevivieron: 3
Tasa de supervivencia: 50 %
Hombres: 3
Mujeres: 3


Lo más interesante aparece al cruzar Sex con Survived:
| Sexo   | Pasajeros | Sobrevivieron | % supervivencia |
| ------ | --------: | ------------: | --------------: |
| Female |         3 |             3 |       **100 %** |
| Male   |         3 |             0 |         **0 %** |


En esta pequeña muestra, todas las mujeres sobrevivieron y todos los hombres fallecieron. Es una señal de que Sex podría ser una variable predictora importante, aunque con solo 6 observaciones no podemos generalizar
